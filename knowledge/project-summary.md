# 文件夹项目总结

最后更新：2026-07-14

## 一、项目作用

该文件夹是一个多无人机反无人机拦截仿真与接口联调项目包，不是单一功能模块。当前系统由两个设备组成：

- **设备一**：郭老师设备/地面统筹设备，负责雷达数据清理、当前战场态势输出、真实无人机操控和指挥大屏显示。
- **设备二**：我方决策外挂，本仓库主要实现对象，负责接收设备一态势输入，完成目标处理、任务分配、路径规划、动作建议和一句话态势总结，并把决策帧回发设备一。

核心仿真由 `simulation/main.py` 运行；`core/common.py` 定义场景、无人机、敌机、运动模型和 `PLAN_EXPORT`；`perception/` 接入设备一态势输入；`decision/` 负责任务分配、重分配、避碰绕飞和 LLM 约束；`station/` 是历史命名的决策输出模块，负责生成 `PlanFrame`、裁剪 `decision_output_frame`、发送 TCP JSON Lines 并处理执行回执。

## 二、当前能做到什么

当前项目能运行多无人机拦截仿真，接入 Redis/UDP/Fusion 态势数据，完成目标稳定处理、任务分配、目标丢失后的保守重规划、无人机返航和重分配。

项目支持语音/文本指令，可调用 Whisper 和 LLM 做态势分析或生成任务约束。决策输出可以通过 TCP JSON Lines 回发设备一，默认按设备一输入帧触发，发送精简 `decision_output_frame`，其中包含一句话态势、任务绑定、动作建议、路径点和下一指令点。

## 三、当前做不到什么

该文件夹目前不是完整外场飞控系统。设备二侧主要完成仿真、分配和规划，不直接负责真实无人机解锁、切模式、起飞、上传航点或 GOTO 执行。真实飞控执行、指挥大屏渲染、设备一内部控制策略和现场链路可靠性仍需联调。
